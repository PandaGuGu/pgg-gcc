## 0. 一句话

用 **pggcc 自研语言**（v4/B1 面）编写**自研编译器本体** `src/boot0.pgc`——单遍、无优化、递归下降，
输入 pggcc 程序文本 → 输出 i386 AT&T 汇编（.s）；全程不调用任何 C/C++ 编译器、不读任何编译器源码；
以"**能编译自己的源码**"（B4 闭台）为毕业标准。

> 命名澄清：`boot0`（B0 编译器）＝自举基础编译器，语义沿 §6.3"用 pggcc 语言从头实现 B0 编译器源码"；
> 实现层面它的语言面＝自面（见 §4），与里程碑编号 B0–B6 互不冲突。

## 1. 目标 / 非目标

**目标**
- 产出 `src/boot0.pgc`：用 pggcc 语言书写的编译器源码（入库，作 B4 闭台与跨链比对对象）。
- 产出 `bin0`：由 `pggcc4`（手写汇编 stage-4）编译 `boot0.pgc` 而得（＝B3 产物，本方案顺带交付）。
- **自面闭合**：boot0 能编译自身源码实际使用的全部构造（B2f 预演 B4 闭台）。

**非目标（登记延后，B5 后在自举链上按 plan §5／P4-二期吸收）**
- switch/case、struct/union、enum、typedef、宏与预处理、位运算、三目、逗号表达式、sizeof、
  多维数组、复合声明符、取模 `%` 等——**若 boot0 源码不依赖，则 B2 一律不实现**。

## 2. 前置差距与对策（用 pggcc 语言写编译器还缺什么）

| 缺口 | v4/B1 现状 | 对策 | 归属 |
|------|------------|------|------|
| 读 stdin | 生成程序模板无 read syscall（仅输出） | **B2-P0**：保留全局 `src_buf`/`src_len`，_start 预读 | P0-S2 |
| 错误退出码 | 模板固定 exit 0（错误路径不可达） | **B2-P0**：内建 `exit(int)`；rc 打印开关 `pg_quiet` | P0-S1/S3 |
| 错误通道 stderr | 模板仅 stdout 输出 | **B2-P0**：内建 `print_err`（fd 2） | P0-S1 |

| 无 struct／多维数组 | 符号表等结构无直接载体 | 扁平 1-D 数组＋手动索引（对齐 v4 面） | B2 源码规范 |
| 字符串比较/复制 | 仅字面量与字符数组 | 自带 `strcmp`/`strcpy`（v4 综合用例已自证） | B2 源码规范 |

## 3. B2-P0 模板扩展（pggcc4.s 增量；D 留痕＋回归门）

生成程序模板现为固定串（.asciz 拼接：s_head_start/s_main_epi 等），按"非破坏扩展＋保留名登记"
模式演进（同 `print_str` 先例，pggcc4.s 文件头 D 系列留痕、ORIGIN v4 备注增 v4.1 行）。

- **S1 内建函数扩展**：内建表（builtin_reg）增 `exit`（1 参，裸 syscall `int $0x80`，1=sys_exit，
  实参→%ebx）、`print_int`（1 参，打印十进制不带换行，复用 f_print_decimal 内核）、
  `print_err`（1 参，字符串写 fd 2＋换行）。运行时模板段对应增发。
- **S2 条件发码·stdin 预读**：发码器扫描全局符号表，**若**存在全局 `src_buf` 与 `src_len`，
  则在 `call f_main` 前发 `read(0, src_buf, N)`（`N`＝src_buf 声明的数组长度 anum，实发实长），
  字节数存 `src_len`；未声明则行为不变（零开销）。
- **S3 条件发码·rc 打印开关**：**若**存在全局 `pg_quiet`，则在 `call f_main` 后发
  `cmpl $0, pg_quiet; jne 直退`（跳过返回值的打印与换行）；未声明则维持打印语义。
- **保留名登记**（同 print_str 先例）：`src_buf` / `src_len` / `pg_quiet`。
- **回归门**：run.sh 原 **57/57 不变**；新增 ≥5 模板用例（读入长度与内容可达、print_int 输出、
  exit 退出码、print_err 走 stderr、pg_quiet 静默）。

## 4. B2 自语言面（boot0 编译面＝其源码使用面，闭合由构造保证）

### 原则（D1，默认推荐：最小自面）
- boot0 **只承诺编译自身源码实际使用的 v4 子集**；每步 B2a–f 的用例覆盖当步全部构造。
- 闭合性＝构造保证：boot0 源码本身是 v4 程序，且每个用到的构造都有对应实现与用例。

### 面清单（粗列，细目直接沿用 §4.4；开工时以 boot0 源码逐条核对登记）
- **词法**：注释 `/* */`；十进制整数（int32 域钳制）；标识符（≤16B）；关键字全集；
  算子全集（`％` 视源码需要与否登记）——**与 pggcc4 词法面一致，boot0 照例再实现一遍**。
- **类型**：`int`/`char`（char 无符号零扩展）；指针层级＝源码实际使用层（预计 ≤2，未用则登记停靠）。
- **声明**：局部/参数/全局（初值：标量、列表、字符串 `.data`，零值 `.bss`）。
- **表达式**：四则、比较、逻辑短路 `&& || !`、一元 `- ! & * ++ --`、后缀 `[] ++ --`、
  复合赋值 `+= -= *= /=`、强转 `(int)(char)(int*)(char*)`、函数调用、字符/字符串字面量（含转义八进制）。
- **语句**：声明/表达式/`return`/块（遮蔽＋栈回收）/`if-else`/`while`/`for`/`do-while`/`break`/`continue`。
- **函数**：`int`/`char`/`void`（返回值指针可）；cdecl；**先定义后调用**（与 v4 同约束，登记）。

### 明确不用面（D1 若选最小自面则一并登记）
switch、struct、enum、typedef、位运算、三目、逗号、sizeof、多维数组、复合声明符、`%`、预处理。

### 协议一致性（对齐 §4.4 §7 既有接口）
- 空白＝空格/`\t`/`\n`/`\r`；语法错误 `error: <位置> <token>`，退出码 2；参数错误退出码 1；
  汇编→stdout、错误→stderr；数字域 int32 钳制；除零/截断语义同 i386 `idivl`（与 C89 一致）。

## 5. B2 实现方案（boot0.pgc，单遍递归下降；自研）

- **模块线**：读入（src_buf/src_len）→ 词法（next_token/esc_decode）→ 符号表（倒序查找＋块底）→
  表达式（优先级爬升，左值求址统一）→ 语句（for inc "扫描＋回放＋peek/restore"）→
  全局声明（.data/.bss 条件切换）→ 发码（L 标号、短路、movzbl 字节读写、左值写回序列）→ 诊断。
- **关键实现点（直接复用 stage-2/3 已验证机制，不另创新）**：
  - 实参从右到左压栈＝扫描实参边界＋自右向左回放（v2 机制）；
  - for 三段发码＋inc 回放＋peek/restore 恢复游标（v3 BUG-3 经验）；
  - 左值体系统一"求址→读→算→写回→值回栈"，`is_assign_ahead` 引号扫描照抄修定版（v4 BUG-1）；
  - 符号表＝扁平 char 缓冲＋并行 int 数组（无 struct，人工索引，登记 D 注）；
  - token 常量＝命名全局常量（.data 初值）；关键字匹配＝自带 strcmp；
  - 诊断＝print_int/print_err 组合，对齐 §4.4 §7。
- **规模预估**：1500–3000 行 / 40–90KB（登记，不设硬限，以闭合为准）。

## 9. 决策点（已确认 2026-08-25）
