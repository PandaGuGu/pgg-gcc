## 1. 实验定义

- **被测对象**：DeepSeek-V4-Flash（大语言模型）对 GCC / 编译器原理的理解水平。
- **方法**：
  1. 凭公开语言标准与通用编译原理**独立推导设计**；
  2. **完全自研实现**（自汇编至高级语言语法）；
  3. 仅在用户**显式放行的阶段**，与真实编译器的**运行时行为**对照验证（不依据源码）。
- **目标路线**：按版本序逐步实现 GCC 支持的语言特性（C90 → C23；C++ 为 backlog），不复制 GCC 源码。
  特性台账与阶段编排见 [plan-language-features.md](plan-language-features.md)。

## 2. 硬约束（红线，源自 ORIGIN.md 原则）

1. 不阅读、不复制、不逐行移植 GCC 及其他编译器源码。
2. 仅依据公开语言标准 / 通用编译原理实现；对照验证**仅限本地运行时行为观察**
   （编译输出、错误信息、汇编产物），不依据源码结构。
3. 源码树与源码包**不得留存于实验环境**；重建须按需重新下载并在日志留痕。
4. **阶段门控（对照开关）**：默认关闭；**当前自研阶段禁止与任何 C/C++ 编译器做行为对照**
   （对照即"参考答案"，会诱发行为克隆式越狱）。
   宿主 gcc 仅承担**构建工具**角色（编译 pggcc 本体），亦不得用于行为对照。

## 4. 实验流程

### 4.1 自研阶段（默认，当前所处阶段）

1. **独立推导设计**（记录设计决策，产出阶段设计文档，可由 Winston 架构师评审把关）；
2. **实现**（`src/`，单文件、无外部依赖的 C 实现）；
3. **自证测试**：`bash tests/run.sh`
   `pggcc "表达式" → as --32 → ld -m elf_i386（+ /lib32 crt/libc）→ 运行 → 与期望值比对`；
   **全程不调用任何 C/C++ 编译器做对照**；
4. **来源登记**：在 ORIGIN 特性清单登记（标准条款 / 实现日期）；
5. **留痕推送**：更新 `docs/logs/YYYY-MM-DD.md`，commit 推送 GitHub。

### 4.2 对照阶段（仅用户显式放行）

前置：按 ORIGIN 原则 5 重建黑盒 gcc295（重新下载 + 构建，全程留痕）；
对照内容：**仅运行时行为**（编译输出、错误信息、汇编产物），不阅读源码；
差异（对齐 diff）登记为"理解偏差项"，作为实验观测产出。

## 5. 实现基线约定（阶段设计共同前提）

- **无蛋实现**（2026-08-25）：编译器本体为**手写 i386 AT&T 汇编**（无 libc），
  构建链 `as --32` → `ld -m elf_i386`（无 crt），全程不调用任何 C/C++ 编译器（见 §6）。
- **单一实现文件、无外部依赖**：stage-0 为 `src/pggcc0.s` 单文件。
- **管线固定四段，每段只认前一段的输出约定，不跨层**：
  `词法（token 流）→ 语法（AST）→ 代码生成（asm 行）→ 汇编文本（.s）`。
- **输出约定**：AT&T 语法 i386 汇编，风格贴近经典 i386 Unix 惯例；
  与真实编译器的 diff 对齐延后至对照放行阶段。
- **Rule of Three**：出现第 3 个同构模块前不做抽象（先内聚过程，不拆子系统）。

## 6. 无蛋引导策略（2026-08-25 用户决策）

**决策**：彻底无蛋——pggcc 不依赖任何 C/C++ 编译器作为"蛋"（引导构建器）。
**"会写汇编"本身也被纳入实验范围**（用户观点）：把词法/语法/代码生成在汇编地板层重新发明一遍，
与 plan"自研阶段＝自汇编至高级语言语法"的定义一致。

- **stage-0 形态**：编译器本体 = 手写 i386 AT&T 汇编（`src/pggcc0.s`），无 libc/crt，
  自含 `_start`、裸 `write` syscall 输出、裸 `exit`；
- **构建链**：`as --32` → `ld -m elf_i386`（无 crt）→ 可直接运行；**不调用任何 C/C++ 编译器**；
- **自证用例程序同样无 libc**：生成代码自带 `_start` + 整数输出 + `exit` syscall；
- **gcc 15.2 退役**：不再承担构建角色，可从环境卸载（卸载动作须登记日志）；
- **as/ld 定位**：助记符→二进制的机械翻译器，属项目地板层既定工具（非 C/C++ 编译器，
  不受对照禁令约束；但任何编译器都不得用作行为对照）；
- **后续路线（待各阶段设计）**：自举（pggcc 编译自身新版本）为主；备选经典路线
  （asm 写最小 C 子集编译器 → 用它编译 C 版 pggcc → 自举）。均为后续决策，非本次范围。
